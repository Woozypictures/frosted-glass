# Claude handoff — Frosted Glass Icon Pack

This ZIP is the merged source project. Continue development from this project rather than from the old `com.mahesh.graphiteglass` project.

## Identity to preserve
- App: Frosted Glass Icon Pack
- Developer: Woozypictures
- Owner: Mahesh Sharma
- Android application ID: `com.woozypictures.frostedglass`
- Version: 2.3 / versionCode 14

The app is assembled and maintained by Woozypictures for Mahesh Sharma. Do not represent third-party icon artwork as created or owned by the app developer; artwork remains subject to the rights and permissions of its respective creators.

## Merge already completed
- 2,069 original PNGs from the supplied Glass icon pack are included.
- Original glass artwork takes precedence for 107 app-package overlaps.
- 80 Claude-only icons are retained, including 12 new device-specific icons.
- The gallery contains 2,149 icons (including 11 new device-specific custom icons).
- All launcher/gallery icon canvases are normalized to 192×192 px. The original 169×169 px icons are upscaled using Lanczos resampling, retaining proportions and transparency without cropping.
- The combined app-filter has 4,104 launcher component mappings after adding the device-confirmed components.
- Original icon-picker categories are retained, with Claude-only artwork added in its own category.

## Important handling notes
- Do not restore the old package ID, old author metadata, old APK or old signing key.
- Do not rename or delete the `_v11` drawable resources casually: the version suffix avoids launcher icon-cache collisions.
- The private release keystore is intentionally NOT in this source ZIP. The owner keeps it separately. Never generate a replacement key for a normal update; updates must use the owner's existing release keystore.
- The original source archive is under `source_assets/` and remains unmodified for provenance. `merge_original_glass_pack.py` documents/repeats the merge and normalizes 169×169 source icon canvases to 192×192. Install Pillow (`python3 -m pip install Pillow`) before rebuilding. If regenerating the base project, run `python3 make_project.py` followed by `python3 merge_original_glass_pack.py`.
- This is an Android source project, not a newly compiled APK. Build and sign it with Android build tools and the owner's separate release keystore.

### Woozypictures package namespace

The active app-filter entries, fully qualified activity names, component list, gallery package index and base icon mapping have been migrated to the Woozypictures namespace. The icon pack's own mapping is `com.woozypictures.frostedglass`. Companion-app entries will match only apps that are installed with the corresponding Woozypictures package IDs. The original source archive is kept unchanged as an archival backup; the merge script applies the namespace migration during regeneration.
